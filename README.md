# VELMARIS — The Poster for a Place That Isn't There

A vintage-style travel poster for **VELMARIS**, an invented place where the
sea falls upward: pine-topped islets float above a dusk sea, fed by
waterfalls that climb from the waves into the sky, under a low golden sun.

The poster is drawn procedurally in this session (`draw.py`, Pillow) and
shipped as `entry.png`; `main.py` (standard library only) copies it into the
output directory and verifies the copy with SHA-256.
